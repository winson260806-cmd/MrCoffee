# Cafe Ordering Website ☕🥐

A responsive cafe ordering website where customers can explore a variety of cafe products such as coffee, bread, and other menu items, then add their selected items to an order.

## 📖 About the Project

This project was created to provide a simple and user-friendly online ordering experience for a cafe. Customers can browse the available menu, view product information, select items, and manage their orders directly through the website.

The website is built entirely using **HTML, CSS, and JavaScript**, with no backend or database integration.

## ✨ Features

- 🍵 Browse cafe menu
- ☕ Coffee and beverage selection
- 🥐 Bread and food selection
- 🛒 Add items to order
- ➕ Adjust order items
- 💰 View order total
- 📱 Responsive user interface
- 🎨 Clean and modern cafe-themed design

## 🛠️ Technologies Used

- **HTML** — Website structure
- **CSS** — Styling and responsive layout
- **JavaScript** — Menu interactions and order functionality
